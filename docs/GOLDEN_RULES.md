# Golden Rules

이 파일은 다음 자산이 자동으로 읽는다:
- `scripts/execute.py` — 매 step 프롬프트에 CLAUDE.md와 함께 항상 주입
- `/review` — 체크리스트 "Golden Rules 위반" 항목의 기준
- `/retro` — 같은 실수가 3회 반복되면 이 파일로 승격을 제안
